# เทียบข้อความที่ผู้ใช้แนบกับข้อมูล Agency ในระบบ

ตรวจวันที่ 4 ตุลาคม 2026 กับ `lib/feesData.ts` ข้อความแนบเป็นสรุปจากผู้ใช้ ไม่ใช่สัญญาหรือประกาศต้นฉบับ การบวกยอดได้ถูกต้องไม่เท่ากับยืนยันราคาและสิทธิ์โปรโมชั่นแล้ว รายงานนี้ไม่ได้เปลี่ยนราคาในระบบ

## ผลราย Agency

### OEG — ข้อมูลใหม่ที่ระบบยังไม่มี และปีโครงการยังขัดกัน

- ข้อความแนบ: สมัคร 3,500 + จอง 18,000 + งวดแรก 37,000 + งวดสอง 35,500 = **94,000 บาท**; กลุ่มใช้งวดสอง 34,000 = **92,500 บาท** ทั้งสองยอดบวกถูกต้อง
- ระบบ: ราคา 2027 ยังไม่ยืนยัน มีราคาเอกสาร **2026 เก่า 111,900 บาท** แสดงเป็นประวัติเท่านั้น จึงไม่ควรเทียบราคาเก่ากับโปรตุลาคมว่าเป็นแพ็กเกจเดียวกัน
- ตรวจใหม่พบหน้าโปรทางการระบุค่าสมัคร 3,500 บาท ลดค่าโครงการเดี่ยว 19,500 / กลุ่ม 3–5 คน 21,000 บาท สอดคล้องส่วนลดจากงวดสุดท้าย 55,000 บาทในข้อความ
- **ปีขัดกันแม้แต่ในเว็บไซต์ทางการ:** เนื้อหาหน้าเว็บเขียน Work and Travel USA 2027 แต่ภาพโปรที่หน้าเดียวกันใช้โลโก้ USA 2026 ข้อความแนบก็เขียน 2026 จึงต้องยืนยันกับเอกสารค่าธรรมเนียมฉบับตรงโปรก่อนใช้เป็นราคา 2027
- หลักฐานที่อ่านได้ยังไม่ยืนยันยอดจอง 18,000 / งวดแรก 37,000 / กำหนดชำระทุกงวด / ยอดรวมทั้งสองราคา
- แหล่งทางการ: https://www.oeg.co.th/news/detail/226
- ภาพทางการ: https://www.oeg.co.th/template/backoffice/plugins/kcfinder/upload/files/Pro1Oct2026Webcover%281%29.png

### IEE — ระบบยังไม่มีรายละเอียดเหล่านี้

- ระบบยังไม่ยืนยันราคาค่าสมัคร ค่าโครงการ และคืนเงิน ไม่ใช่ระบบระบุราคาเป็นศูนย์
- ตามข้อความ: สมัคร 7,900 + งวดแรก 20,000 + งวดสอง Classic 59,400 / Signature 54,400 / Exclusive 59,400
- รวม **87,300 / 82,300 / 87,300 บาท** ตามลำดับ ก่อนค่ารัฐบาลและส่วนลดอื่น ห้ามหักค่าดำเนินการ 8,000 ซ้ำหากราคา Classic รวมสิทธิ์ฟรีแล้ว
- SEVIS 3,900 บาท / สิทธิ์ 30 คนแรก / ส่วนลดคู่และกลุ่ม / คืน 700–1,100 USD ยังไม่มีประกาศต้นฉบับที่ยืนยันตรงกับข้อความในการตรวจครั้งนี้
- ส่วนลดที่เขียนว่า “สูงสุด” ต้องตรวจว่าต่อคนหรือรวมกลุ่ม รวมสิทธิ์ใดบ้าง และใช้ร่วมกันได้หรือไม่ ห้ามนำยอดสูงสุดมาหักอัตโนมัติ
- ข้อความคืนเงินเป็นตัวอย่างหลายเหตุการณ์ ไม่ใช่ตารางยอดคืนแยก Classic / Signature / Exclusive จึงยังคำนวณความเสี่ยงสุทธิรายแพ็กเกจไม่ได้
- แหล่งที่ระบบตรวจ: https://www.ieethailand.com/work-and-travel-new/

### New Step — ตรงบางส่วน แต่ข้อความเพิ่มราคาเฉพาะแพ็กเกจ

- ตรงกับระบบ: Summer สมัคร 5,900 / V Care 17,900 บาท, ลดค่าโครงการ 32,000 บาท, ค่าเลือกงาน 0 / 5,000 / 10,000 บาท, SEVIS ที่ Agency ระบุ 3,900 บาท และจองเครื่องบินเองได้
- ไปก่อนจ่ายทีหลัง 6,900 + 30,000 + 45,000 = **81,900 บาท** ตรงกับระบบและหน้าโปรทางการ
- หน้าโปรทางการยืนยันว่าเมื่อวีซ่าไม่ผ่านไม่ต้องจ่ายงวดหลังกลับ แม้หน้าเว็บเรียกเลขงวดไม่สอดคล้องกัน
- ข้อความแนบขาดเงื่อนไขสำคัญ: Summer ไปก่อนจ่ายทีหลัง **เฉพาะ Lifeguard ใน Washington D.C. / Maryland / Virginia**; V Care ต้องผ่านวัดระดับภาษา
- งวดสอง 47,900 บาทและคืนวีซ่าไม่ผ่าน 25,000 บาทของโปรทั่วไปยังไม่ได้ยืนยันจากหลักฐานต้นฉบับในการตรวจนี้ ระบบจึงใช้ช่วงค่าโครงการทั่วไป 54,900–89,900 บาทแทนการยืนยันราคาเฉพาะโปร
- ตามข้อความ โปรทั่วไป 5,900 + 30,000 + 47,900 = **83,800 บาท**; V Care 17,900 + 30,000 + 47,900 = **95,800 บาท** ก่อนค่าเลือกงาน / SEVIS / วีซ่า / ค่าเดินทาง
- ถ้าโปรจ่ายทีหลังต้องเสีย Extra Charge 10,000 จริง ยอดจะเป็น **91,900 บาท** ก่อนรายการอื่น แต่หน้าโปรข้อความที่ตรวจยังไม่ยืนยันว่าค่าดังกล่าวบังคับทุกคน
- 47,900 ถูกระบุว่าหักส่วนลด 32,000 แล้ว ห้ามหักอีกครั้ง คืนเต็มจำนวนของ V Care หมายถึงค่าโครงการ ไม่ได้ยืนยันคืนค่าสมัครและค่าใช้จ่ายทั้งหมด
- แหล่งทางการ: https://newstepthailand.com/promotions และ https://newstepthailand.com/blog/expenses-work-and-travel-usa

### ACADEX — ค่าสมัครต่างกัน และต้องคำนวณสิทธิ์แยก

- ระบบพบค่าสมัคร **3,900 บาท** บนหน้ารวมงาน Summer 2027 ข้อความแนบให้ **3,500 / 4,900 บาท** จึงต่างกัน ต้องตรวจว่าเป็นคนละช่วงโปรหรือคนละแพ็กเกจ ยังเลือกแทนกันไม่ได้
- ระบบยังไม่มีราคาค่างวด 10,000 / 15,000 / 33,900 และราคาแยก Group Z/Y/X/A หรือเส้นตายที่แนบมา
- ข้อความระบุว่างวด 33,900 **รวม SEVIS 3,900 แล้ว** ถ้าใช้ราคาชุดนี้ห้ามบวก SEVIS ซ้ำ
- ข้อความห้ามผู้สมัคร 3,500 ใช้ส่วนลดกลุ่ม 2,000 บาท ดังนั้นห้ามจับค่าสมัคร 3,500 ไปบวกงวดสุดท้ายที่ลดกลุ่มแล้ว
- ตารางต่อไปนี้เป็นการคำนวณจากข้อความเท่านั้น สมมติค่าสมัครแยกจากสี่งวด และส่วนลดกลุ่ม 2,000 ใช้ได้สำหรับผู้สมัคร 4,900; ไม่รวมส่วนลดศิษย์เก่าและค่าใช้จ่ายอื่น:

| กลุ่มงาน | รวม 4 งวดก่อนส่วนลดกลุ่ม (รวม SEVIS) | บวกค่าสมัคร 3,500 ไม่ใช้ส่วนลดกลุ่ม | บวกค่าสมัคร 4,900 และลดกลุ่ม 2,000 เมื่อมีสิทธิ์ |
|---|---:|---:|---:|
| Z | 84,200 | 87,700 | 87,100 |
| Y | 90,700 | 94,200 | 93,600 |
| X | 93,700 | 97,200 | 96,600 |
| A | 95,700 | 99,200 | 98,600 |

- สิทธิ์เปลี่ยนงานฟรีที่ระบบพบในงาน Yellowstone เป็นเงื่อนไขเฉพาะงาน ไม่ใช่สิทธิ์ทุกแพ็กเกจ จึงยังใช้แทนข้อกำหนดค่าสมัคร 3,500 / 4,900 ไม่ได้
- แหล่งทางการ: https://www.acadexthailand.com/program/work-and-travel-summer/ และ https://www.acadexthailand.com/work-and-travel-2/

### iHappy — ราคา Summer ตรง แต่จำนวนคนรับส่วนลดไม่ตรง

- Summer Adventure: 4,500 + 22,000 + 23,000 + 32,900 = **82,400 บาท** ตรงกับการ์ด Summer ในระบบและโปสเตอร์ทางการ (สมัคร 4,500 + ค่าโครงการ 77,900)
- Summer Visa Protection: 17,500 + 34,000 + 34,900 = **86,400 บาท** ตรงกับการ์ด Summer Protection และโปสเตอร์ทางการ
- **จุดขัดกัน:** ข้อความ Adventure ระบุเพื่อน 2 คนลด 1,000 บาท แต่โปสเตอร์ทางการระบุ **สมัคร 3 คน** ลด 1,000 บาท ระบบตรงกับโปสเตอร์ กลุ่ม 5 คนลด 1,500 ตรงกัน
- Adventure หลังส่วนลดตามโปสเตอร์: 3 คน **81,400 บาท** / 5 คน **80,900 บาท**; Protection: 3 คน **85,400 บาท** / 5 คน **84,900 บาท** ก่อนค่าใช้จ่ายแยกและเมื่อได้รับสิทธิ์ส่วนลด
- หน้ารายละเอียดหลักของระบบเป็น **Spring All in One 3,500 + 82,000 = 85,500 บาท รวม VISA/SEVIS** ข้อความแนบเป็น Summer จึงห้ามใช้มาแทนกัน หรือถือว่า Summer รวม VISA/SEVIS เหมือน Spring
- งวดชำระ, ค่า Job Placement 4,200 / 5,200 / 7,200 / 8,900, SEVIS Summer 3,900 และยอดคืนเงินยังไม่มีหลักฐานต้นฉบับครบในการตรวจนี้ ระบบยังไม่ยืนยัน
- แม้ข้อความ Protection ระบุคืนเต็ม ก็ระบุเฉพาะค่าโครงการงวด 1 และ 2 ไม่ใช่ค่าสมัคร 17,500 หรือยอดค่าใช้จ่ายทั้งหมด
- โปสเตอร์ทางการ: https://www.ihappyeducation.com/wp-content/uploads/2026/09/Summer-2.png และ https://www.ihappyeducation.com/wp-content/uploads/2026/09/SM-Protect-3.png

### ALC — ตัวเลขใหม่ ระบบยังไม่ยืนยัน

- ระบบยืนยันได้ชื่อ sponsor จาก API งาน แต่ยังไม่มีราคา 8,000 / ค่าโครงการ 78,000 / ค่าธรรมเนียมนักเรียนแลกเปลี่ยน 3,800 / ค่า Location ตามข้อความ
- ค่างวด 20,000 + 22,000 + 36,000 = **78,000 บาท** ถูกต้อง; งวดสุดท้ายพร้อมค่าธรรมเนียม 3,800 = **39,800 บาท**
- รวมสมัคร 8,000 + ค่าโครงการ 78,000 + ค่าธรรมเนียม 3,800 = **89,800 บาท** ก่อน Location / วีซ่า / ตั๋ว / ที่พัก / เงินสำรอง
- บวก Location: Standard **89,800**, Premium **95,800**, Exclusive **99,300**, Supreme **101,800 บาท** ก่อนรายการอื่น
- 78,000 หักโปร 10,000 แล้ว ห้ามหักซ้ำ และห้ามใช้ค่าธรรมเนียม 3,900 ของ Agency อื่นแทน **3,800** ที่ข้อความนี้ระบุ
- ยังต้องมีประกาศต้นฉบับหรือใบเสนอราคาตรงโปรก่อนใช้เป็นราคายืนยัน โดยเฉพาะรายการที่รวมและไม่รวม
- แหล่งระบบ: https://myalcapp.com/work-and-travel

## ขอบเขตที่ยังเทียบไม่ได้

ข้อความแนบมี 6 Agency ไม่มี Interchange และ I4 Group และไม่ได้ให้รายชื่อ sponsor ของแต่ละ Agency จึงยังตรวจความตรงกันของสอง Agency ที่ขาดและ sponsor จากเอกสารนี้ไม่ได้

ยอดที่คำนวณในรายงานเป็นยอดตามข้อความและรายการที่ระบุเท่านั้น ไม่ใช่งบเดินทางรวม ไม่รับรองสิทธิ์โปรหรือเงื่อนไขคืนเงิน การอัปเดตข้อมูลยืนยันควรใช้โปสเตอร์/สัญญาต้นฉบับที่ระบุปี ฤดูกาล แพ็กเกจ ช่วงสมัคร และเงื่อนไขร่วมโปรตรงกัน
